Box Model e Flexbox

Estudando Flexbox

Nesta atividade foram utilizados conceitos de Box Model, como Content, Padding, Border e Margin, além das propriedades do Flexbox para organizar os elementos da página.

Content
Padding
Border
Margin

Exemplos de Flexbox

01

Display

Define o elemento como um container flexível.

display: flex;
02

Flex Direction

Define a direção dos elementos.

flex-direction: row;
03

Flex Wrap

Permite quebrar os elementos para outra linha.

flex-wrap: wrap;
04

Justify Content

Alinha os elementos horizontalmente.

justify-content: center;
05

Align Items

Realiza o alinhamento dos itens.

align-items: center;
06

Align Content

Controla o alinhamento das linhas.

align-content: center;
07

Gap

Cria um espaço entre os elementos.

gap: 20px;
08

Row Gap

Cria espaço entre as linhas.

row-gap: 20px;
09

Column Gap

Cria espaço entre as colunas.

column-gap: 20px;
10

Order

Pode alterar a ordem de um item.

order: 1;
11

Flex Grow

Define quanto um item pode crescer.

flex-grow: 1;
12

Flex Shrink

Define quanto um item pode diminuir.

flex-shrink: 1;
13

Flex Basis

Define o tamanho inicial de um item.

flex-basis: 200px;
14

Flex

Junta algumas propriedades do Flexbox.

flex: 1;
15

Align Self

Alinha apenas um item específico.

align-self: center;
16

Flex Flow

Junta direction e wrap.

flex-flow: row wrap;
17

Direction Column

Organiza os elementos em coluna.

flex-direction: column;
18

Space Between

Cria espaço entre os elementos.

justify-content: space-between;
19

Space Around

Distribui espaço ao redor dos elementos.

justify-content: space-around;
20

Flex End

Posiciona os elementos no final.

justify-content: flex-end;
